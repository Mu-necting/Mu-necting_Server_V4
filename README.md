# Mu-necting_Server_V4
    
## 📌 기술 스택
**언어 및 빌드**
- Java 21
- Gradle

**프레임워크 및 라이브러리**
- spring boot 3.3.1
- spring data JPA
- spring security
- spring retry

**데이터베이스**
- 개발 및 프로덕션
  - PostgreSQL, Redis
- 테스트
  - H2 Database, Embedded Redis

**외부 API 및 서비스**
- Spotify API
- Google API Client
